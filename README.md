`main.py` (pure Python stdlib, no third-party libraries) writes exactly one line of text to `/output/entry.txt` — an original one-line roast of an alarm clock that rings at 6 AM on a Saturday. The output is deterministic: every run produces byte-identical output.

> My alarm clock rang at 6 AM on a Saturday like a coworker who volunteers for the weekend shift just to prove it has no life either.

## Run it

```sh
python3 main.py
```
